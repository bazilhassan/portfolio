# Bazil Hassan — Portfolio V1

A free, static portfolio website for GitHub Pages.

## Before publishing

Open `index.html` and replace:
- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/`
- `https://github.com/`

You should also replace the placeholder experience/company information with the exact details from your CV.

## Free GitHub Pages deployment

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html`.
3. Open repository Settings → Pages.
4. Select Deploy from branch → `main` → `/root`.
5. Save.
6. GitHub will provide your free `https://yourusername.github.io` URL.
